# Smart Counter OS

This repository hosts the landing page for Smart Counter OS, a business automation platform for laundries and garment service businesses.

## About

The website showcases a modern sales landing page for a WhatsApp/Telegram-based laundry operating system that helps businesses:

- manage garment intake and billing
- track orders in real time
- protect high-value garments with VIP care workflows
- automate WhatsApp-based customer communication
- simplify doorstep pickup coordination
